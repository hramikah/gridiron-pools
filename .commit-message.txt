Printing: pick sheets and Master Standings for all three pools

Adds a Print button to the Gridiron, Loser and Drop Dead pick pages and the
@media print rules behind it. Nothing on screen changes.

- static/css/style.css: a Print section at the end. Site furniture (nav, the
  frozen-clock and LOCAL TEST banners, the countdown, the floating save bar,
  every button and pick control) is dropped; sticky table headers unstick;
  win/loss/push keep their colour via print-color-adjust: exact; one entry per
  sheet when a player controls more than one team.
- templates/gridiron/pick.html, templates/loser/pick.html,
  templates/dropdead/pick.html: the Print button, a print-only sheet header
  (pool, week, deadline, player, entry label, and per pool: picks used and
  penalty losses / running points total / Alive or Eliminated), and a
  print-only board of the week's games.
- templates/base.html: no-print on the two site banners, which are inline-styled
  divs with no class of their own.

The board is print-only and separate from the pick table on purpose: the pick
table is not rendered at all once the deadline passes, once a Gridiron entry
has used all its picks, or -- in Loser and Drop Dead -- the moment a pick is
locked in. That is exactly when someone reaches for Print, so the table cannot
be relied on to carry the week's games onto paper. The screen table is hidden
in print so the two can never both appear.

Each board carries what its pool picks on: Gridiron lists kickoff, spread and
O/U per game; Loser puts each team's point value beside its name; Drop Dead
marks teams the entry has already spent. All three mark the entry's own picks,
with WIN/LOSS/PUSH once scored.

Verified by rendering the pages headlessly against a 150-player copy of the
testbed database and producing real PDFs: Gridiron in four states (open week
part picked, scored past week, makeup week at 8/8 with 2 penalty losses,
nothing picked) and Loser and Drop Dead with and without a pick in. A 24-game
NFL slate plus the college board fits two sheets; Loser and Drop Dead fit one.

Master Standings (templates/standings.html) gets the same treatment: a Print
button and a print-only header inside each of the three pool tabs. Bootstrap
shows only the active tab pane, so printing gives that pool's table and nothing
else; the tab strip itself does not print. Drop Dead's "Week by week" grid is
marked no-print -- one column per unlocked week by 150 rows does not fit Letter,
and the standings table is what was asked for.

The standings tables carry no .table-responsive wrapper, so the phone
breakpoint turns them into their own scroll containers with sticky rank and
name columns. At print width that breakpoint is live, and without undoing it
the table printed as a clipped block. The green gradient header is swapped for
flat grey, and Alive / Out keep distinguishable colour the way win/loss do.
150 entries print as 4 sheets with the column header repeated on each.

Every printed sheet carries a "Printed <day> <date> at <time> Eastern" line in
its header -- pick sheets and standings alike. templates/_print_stamp.html
renders the server clock as a fallback and app.py exposes helpers.now_eastern
to Jinja for it, but a script in base.html rewrites every .print-timestamp from
the BROWSER clock on load, on beforeprint, and when the print media query goes
live. That matters: someone opens the standings in the morning and prints at
six, and the paper has to say six. Verified both paths -- the beforeprint
rewrite restamps a deliberately staled node, and a scripts-disabled context
falls back to the server value.

The Weekly Picks reports (templates/week_report.html) get the same button and
header, for all three pools. Those tables are plain Bootstrap .table rather
than .standings, so the print block squeezes them too. The Gridiron report is a
150-player by 5-pick grid whose cells carry their own padding (.p-0 on the td,
.px-2.py-2 on a div inside) and an inline min-height for makeup rows; left
alone it printed 11 players to a page, 17 sheets. Author !important beats an
inline style, which is how the min-height and the .72rem matchup line come
down -- 11 sheets now, still legible. Loser and Drop Dead reports are 4 each.

56 tests pass.

Known gap: an eliminated Drop Dead entry prints its header, teams used and the
buy-back notice, but no board -- the board sits inside the active-entry branch.
