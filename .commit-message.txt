Fix Data page 500: no database objects in the Wrapped cache

league_week() is cached for 10 minutes across requests, and it held Pick
rows. The next visitor's "Your week" card lazy-loaded pick.team from a row
whose session was gone -> DetachedInstanceError -> Internal Server Error for
anyone who wasn't the request that filled the cache. Picks are now stored as
plain dicts; new test checks the cached data holds no database objects and
that a second request served from the cache works.

Also adds check-data-page.command / check-data-page2.command: read-only
diagnostics (the second runs the page against a /tmp copy of the live DB).
